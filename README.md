# Autonomous Desktop Agent

Это проект локального автономного desktop-агента для Windows, созданного с использованием Python, Flask и Ollama. Агент управляется через веб-интерфейс и способен выполнять широкий спектр задач: от простого диалога до автоматизации действий на рабочем столе.

## Основные возможности

-   **Веб-интерфейс:** Удобный чат для взаимодействия с агентом, доступный через браузер.
-   **Система чатов:** Поддержка нескольких чатов с сохранением истории в базе данных SQLite.
-   **Выбор моделей:** Возможность выбора любой модели, доступной в вашем локальном экземпляре Ollama.
-   **Два режима работы:**
    -   **Диалоговый режим:** Для обычных вопросов и ответов.
    -   **Агентный режим:** Для выполнения сложных задач, запускаемых командой `/task`.
-   **Автономный цикл Plan-Act-Observe:** Агент самостоятельно планирует шаги, выполняет действия, анализирует результаты и корректирует свой план до тех пор, пока задача не будет решена.
-   **Широкий набор инструментов:**
    -   Работа с файловой системой (чтение, запись, листинг).
    -   Безопасное выполнение shell-команд.
    -   Управление GUI (клики мыши, ввод текста, горячие клавиши).
    -   Управление окнами (активация, максимизация).
    -   Создание скриншотов для визуального анализа.
-   **Безопасность:** Встроенные защитные механизмы, предотвращающие изменение системных файлов и выполнение опасных команд.

## Архитектура

Система состоит из трех ключевых компонентов:
1.  **Frontend (Web UI):** Статический веб-интерфейс (HTML, CSS, JS), который взаимодействует с бэкендом.
2.  **Backend (Flask Server):** Ядро приложения, которое обслуживает UI, управляет чатами, взаимодействует с Ollama и запускает Agent Core.
3.  **Agent Core:** Мозг и руки агента, работающие в отдельном потоке. Он выполняет задачи в автономном цикле.

## Предварительные требования

Перед началом убедитесь, что у вас установлены:
-   **Python 3.12+**
-   **Ollama:** Убедитесь, что Ollama [установлен](https://ollama.com/) и запущен.
-   **Модель Ollama:** Загрузите хотя бы одну модель, например, Llama 3:
    ```sh
    ollama pull llama3
    ```

## Установка и запуск

1.  **Клонируйте репозиторий:**
    ```sh
    git clone <URL_репозитория>
    cd <папка_репозитория>
    ```

2.  **Создайте виртуальное окружение и установите зависимости:**
    ```sh
    python -m venv venv
    source venv/bin/activate  # Для Windows: venv\Scripts\activate
    pip install -r requirements.txt
    ```

3.  **Запустите сервер:**
    ```sh
    python run.py
    ```
    Сервер будет запущен и доступен по адресу `http://127.0.0.1:5000`.

## Как использовать

1.  **Откройте веб-интерфейс:** Перейдите по адресу `http://127.0.0.1:5000` в вашем браузере.

2.  **Выберите модель:** В левой нижней части экрана выберите модель Ollama, которую хотите использовать.

3.  **Начните новый чат:** Нажмите кнопку `+`, чтобы создать новый чат.

4.  **Взаимодействуйте с агентом:**
    -   **Для обычного разговора:** Просто введите ваш вопрос и нажмите "Send".
    -   **Для постановки задачи:** Начните ваше сообщение с команды `/task`, а затем опишите задачу.

    **Пример задачи:**
    ```
    /task создай файл hello.py с кодом print("Hello, World!") и запусти его
    ```

    Агент начнет выполнять задачу, и вы будете видеть все его шаги, мысли и результаты в реальном времени прямо в чате.
